# RhythmicVisual v12 — Web (1.0.0)

openFrameworks **v11** 웹 포트(`../v11/`)를 바탕으로 전시용으로 단순화한 버전입니다. v11 웹 폴더는 그대로 보존합니다. Vercel Functions와 private Blob 저장소로 모든 접속자의 리듬 기록을 보존하며, v11과 같은 저장소를 이어서 사용하므로 지금까지의 히스토리가 그대로 보입니다.

## 실행

Node.js 20 이상에서, **이 폴더(`v12`) 안에서** 실행합니다.

```sh
npm run dev      # http://127.0.0.1:5173 (메모리 공유 갤러리 포함)
npm test
npm run build    # dist/
```

## Vercel 배포

Vercel 프로젝트 `rhythm-visualiser` · **Root Directory `v12`** · Build `npm run build` · Output `dist` · Framework Other. Blob 저장소(`BLOB_READ_WRITE_TOKEN`)는 프로젝트에 연결된 것을 그대로 씁니다.

## v12 동작

- **첫 화면**: 공유 갤러리를 먼저 불러온 뒤 첫 프레임을 그립니다. 접속하자마자 지금까지의 히스토리가 보이고, 기본 리듬이 잠깐 그려졌다가 바뀌는 일이 없습니다. 4초 안에 갤러리를 못 받으면(오프라인) 로컬 루프로 시작합니다.
- **시작 박자**: 마지막 사용자가 선택한 박자(`lastMeter`)로 시작합니다. 인덱스에 없으면 맨 앞 묶음의 박자, 그것도 없으면 12/3.
- **박자 순서**: 분자(소박 합산) 내림차순, 같으면 분모가 큰 것부터 — 40/4, 40/2, 24/3, 24/2, 20/2, 16/4, 12/3, 8/4, 6/3, 4/4. 다이얼·메뉴·좌우 화살표가 이 순서를 따릅니다. 저장된 기록의 박자 번호는 바꾸지 않았습니다.
- **기본값**: white brightness 0.5 · spectrum opacity 0.1 · spread 250 · softness 1 · resolution 0.1.
- **고정된 모드**: 레이아웃 SHIFT RIGHT, 스펙트럼 Area: Alternating, 라이트 RAINBOW, 커브 FLAT. 해당 메뉴와 ARC degree 슬라이더는 없습니다. 예전 HELIX 기록도 평면 커브로 그립니다.
- **삭제한 메뉴**: Version 드롭다운(왼쪽 아래에 `v12` 표기), Connect Palette Gear, Fullscreen.
- **All clear**: 모든 접속자 화면의 공유 갤러리를 비웁니다. 영구 보관 기록(archive)은 지우지 않으며, 마지막 박자는 유지됩니다. 비운 뒤 화면은 빈 상태이고, 다음 리듬부터 다시 쌓입니다. **Restart my rhythm**은 현재 박자의 기본 리듬을 새로 그립니다.
- **소리**: 징 하나. 화면 맨 앞 가장 최근 커브의 큰 원(리플)이 생길 때마다 울립니다. 화면이 비어 있으면 울리지 않습니다.

## 브라우저에 맞춘 차이와 제한

- 오디오는 브라우저 정책상 **Enable sound**를 눌러야 활성화됩니다. 소리 로딩 후 다음 리플부터 예약합니다. 별도의 Web Audio 시간축과 25ms 스케줄러/350ms lookahead를 사용해 렌더 프레임과 분리했습니다. 탭을 백그라운드로 보내거나 OS가 앱을 중단할 때의 오디오 동작은 브라우저 정책에 영향을 받습니다.
- 원본 UI를 HTML 컨트롤로 재구성했습니다. 휴대폰에서는 Controls로 패널을 열고 닫습니다. 모바일 크기는 데스크톱 Chrome 에뮬레이션으로 검증했으며, 실제 iOS/Safari·Android 기기 검증은 수행하지 않았습니다.
- 메인 폰트는 시스템 Georgia/Times/serif를 사용합니다. macOS 전용 폰트를 재배포하지 않습니다.
- WebGL 2가 필요합니다. GPU의 부동소수점 렌더 타깃·MSAA 지원에 따라 화질/속도는 달라집니다. 결과는 네이티브 픽셀 단위 동일성을 보장하지 않으며, 하드웨어 필터링에 미세한 차이가 있습니다.
- SVG는 브라우저 다운로드 방식입니다. 카메라 쪽으로 투영된 전체 배치를 fit하며, UI에 가려진 부분도 포함합니다. 웹 SVG는 캐시된 폴리라인을 벡터 path로 내보내며, OF의 평면 SVG에서 쓰던 정확한 A 원호 명령과는 파일 구조가 다릅니다.
- 공개용 파일에는 원본과 테스트 데이터를 포함하지 않습니다. 초기 로딩은 로컬 Three.js·앱·셰이더만 사용하고, 징 소리 파일은 오디오 활성화 때 로드합니다.

## 검증

`npm test`(단위 18개)와 `tests/browser.mjs`, `tests/stress-browser.mjs`(Chrome + Playwright, `PLAYWRIGHT_MODULE` 지정 가능)로 확인합니다. 브라우저 테스트는 첫 프레임의 공유 히스토리, 마지막 박자 시작, v12 기본값과 삭제된 메뉴, 박자 순서, 두 화면에서의 All clear, 리플에 맞춘 징을 검사합니다.

## v11 웹 변경 기록

### 1.2.1 (2026-11-26)

- 리듬을 적용할 때마다 화면이 공유 갤러리 장면에서 로컬 전용 장면으로 바뀌었다가 저장이 끝나면 돌아오며 커브와 지난 기록이 튀던 문제 수정. 저장 중에도 공유 갤러리에 내 기록을 미리 붙인 같은 장면을 보여줍니다.

### 1.2.0 (2026-11-24)

- 소리 기준을 화면의 큰 원(리플)으로 변경. 징은 화면 맨 앞, 가장 최근 리듬커브의 리플이 생길 때마다 울립니다.
- 장구(리듬) 소리 기능 삭제: 버튼, 소리 파일 16개, 관련 코드 제거. 볼륨 슬라이더는 징 볼륨으로 바뀌었습니다.
- 프레임이 길어져도 징이 빠지지 않도록 예약 범위를 넓히고, 늦게 발견한 징은 앞부분을 건너뛰어 재생합니다.

### 1.1.0 (2026-11-24)

- 버튼을 클릭한 뒤 Space·방향키가 막히고 Space가 그 버튼을 다시 누르던 문제 수정. 버튼은 클릭 후 포커스를 놓으며, 단축키는 텍스트 입력과 메뉴에서만 막습니다.
- 내 리듬이 서버에 저장되는 순간 커브가 처음부터 다시 그려지던 문제 수정. 내 커브는 소리와 같은 로컬 시계를 유지합니다. 다른 관람객의 기록은 서버 시계 차이를 보정해 표시합니다.
- 거부된 기록 하나가 대기열과 갤러리 읽기를 영구히 막던 문제 수정.
- 한 박자 묶음에 기록이 9개 이상 쌓이면 묶음 전체 색이 바뀌던 문제 수정. 묶음은 첫 기록 번호를 고유 ID로 유지합니다(기존 인덱스는 자동 이전).
- 오디오와 화면 시계를 계속 다시 맞춥니다. 탭 백그라운드·일시정지 후에도 소리가 늦어지지 않고, 출력 지연을 보정합니다.
- 저장 API: Origin 없음·`null`일 때 500 대신 403, 리듬 문자열 공백 정규화, 요청 빈도 제한.
- 성능: 박자 표기 색을 비동기로 읽어 GPU 대기를 없앴고, 카메라를 움직이는 동안 지난 레이어는 빛 형상을 재사용합니다. 64세트에서 카메라 회전 시 프레임당 형상 재계산이 약 0.4초에서 거의 0으로 줄었고, 멈추면 원래 품질로 다시 계산합니다.
